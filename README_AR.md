# خادم يلا بينا — بداية الربط

1. ارفع الملفات الثلاثة إلى جذر مستودع GitHub: `package.json` و`server.js` و`render.yaml`. لا تستبدل `index.html` الخاص بالعملاء.
2. في Render اختر New + ثم Blueprint، واربط مستودع `klabsh59-hue/Yalabena` والفرع `main`.
3. أدخل `ADMIN_PHONE` بصيغة دولية و`ADMIN_PASSWORD` قوية وفريدة عند طلب القيم. لا تضع كلمة المرور في GitHub أو المحادثة.
4. Render ينشئ خدمة API وقاعدة PostgreSQL ويولد `JWT_SECRET` تلقائيًا.
5. بعد النشر اختبر `/health`. ثم غيّر رابط API في شاشة الإدارة إلى `https://اسم-الخدمة.onrender.com/v1` بدل `http://localhost:3000/v1`.

تنبيه: هذا تأسيس أولي. لم يتم ربط نموذج طلب العميل الحالي أو الدفع أو السحب المالي بعد. لا تستخدمه للتشغيل التجاري قبل استكمال واختبار دورة الطلب والصلاحيات.
